Implementing AD

EnzymeImplicitAD.calculate_∂y∂x — Function
calculate_∂y∂x(implicit_problem, x, y) -> ∂y∂x

Return an object ∂y∂x that acts like a Jacobian matrix when pre- or post-multiplied by a conformable vector, via the methods calculate_pushforward! and accumulate_pullback!.

The return type should depend only on implicit_problem, and should be consistent with [get_∂y∂x_type]((@ref).

The implementation is free to ignore y, eg if it can obtain a solution from x. However, this function should only be called when there is a solution (success == true), otherwise consequences are undefined.

EnzymeImplicitAD.get_buffers — Function
get_buffers(implicit_problem) -> (; x, y, dy, r, dr)

Return an object which contains the following buffers, which are accessible as properties. Each is a vector, with lengths consistent with the corresponding dimension in get_dimensions.

  • buffer_r is a vector of length n_y
  • buffer_dr is a tuple of 4 vectors, each of length n_y
  • buffer_x is a vector of length n_x
  • buffer_y is a vector of length n_y
  • buffer_dy is a tuple of 4 vectors, each of length n_y

The element type of buffers should be consistent with get_preferred_eltype.

The hardcoded constant 4 is available as AD_CHUNKS.

The fallback method reallocates these for each use, implementations can provide reusable buffers. However, the buffers should not be used concurrently, see independent_copy.
