Benchmarking and sanity checks

Benchmarking

The utilities below help the user benchmark solutions and $∂y/∂x$ calculations.

EnzymeImplicitAD.benchmark_and_stresstest — Function
benchmark_and_stresstest(
    implicit_problem;
    count=1000,
    max_solver_errors=20,
    max_partial_errors=20,
    rng=Random.default_rng()
) -> benchmarks::Benchmarks

Benchmark and stress test implicit_problem.

Keyword arguments

  • counts: test the problem with this many inputs

  • max_solver_error, max_partial_errors: stop after this many errors have been logged (whichever is first)

  • rng: random number generator to use

EnzymeImplicitAD.sanity_checks — Function
sanity_checks(
    implicit_problem;
    residual_l2norm
) -> checks::SanityChecks

Check that the interface implemented to implicit_problem conforms to the expected API. See SanityChecks, which prints as a nice summary.

Checks are not necessarily comprehensive, and may change without major version changes. The user can access the property checks.all_ok::Bool, the rest of the fields can be used for debugging but are not part of the API.

Keyword arguments

  • residual_l2norm: the Euclidean norm used to check the residual
source
EnzymeImplicitAD.SanityChecks — Type

Results from sanity_checks.

Each field is either missing (test not performed), nothing (test passed), or an error-backtrace pair. In addition, the property all_ok::Bool is supported, which is true iff all checks passed.
